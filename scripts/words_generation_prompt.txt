Ты — эксперт-лексикограф и методист по обучению английскому языку. Твоя задача — составить список английских слов для приложения интервального повторения.

ТРЕБОВАНИЯ К СЛОВАМ:
1. Лемма (lemma) — базовая форма слова:
   - Существительные: единственное число (кроме слов, которые употребляются только во множественном: "people", "children").
   - Глаголы: инфинитив без "to".
   - Прилагательные/наречия: базовая форма.
   - Предлоги, местоимения, союзы: как есть.
2. Часть речи (pos) — одно из: "noun", "verb", "adjective", "adverb", "pronoun", "preposition", "conjunction", "interjection".
3. Уровень (level) — один из: "A1", "A2", "B1", "B2", "C1", "C2". Оценивай уровень честно по CEFR.
4. Переводы (translations) — от 1 до 5 самых употребительных русских переводов. Без пояснений в скобках.
5. Словари (dictionaries) — массив, в какие тематические словари входит слово:
   - "general" — общеупотребительная лексика (входит почти всё).
   - "it" — IT-терминология, технологии, программирование.
   - "travel" — путешествия, транспорт, гостиницы, еда, аэропорт.
   Слово может входить в несколько словарей одновременно.

КОЛИЧЕСТВО: сгенерируй {count} слов уровня {level}.

ФОРМАТ ОТВЕТА — СТРОГО валидный JSON без markdown-обёрток (без ```json), без комментариев:
{
  "words": [
    {
      "lemma": "run",
      "pos": "verb",
      "level": "A1",
      "translations": ["бегать", "бежать", "управлять"],
      "dictionaries": ["general", "travel"]
    }
  ]
}

ВАЖНО:
- Не дублируй слова.
- Не добавляй лишних ключей в объекты.
- Ответ должен парситься через json.loads() без ошибок.
- Только JSON, ничего больше.
